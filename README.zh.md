# dsh-base-plugin

[English](README.md) | 中文

DeepSeek Harness（DSH）基础插件：插件市场、MCP 服务器管理与技能浏览——全部通过设置页面提供，
不改动 DSH 源代码。界面文案跟随 DSH 设置里的语言（中文 / English），所有页面适配手机宽度屏幕
（见下文「移动端适配」）。

## 功能

1. **插件市场** —— 设置 → 插件 分区里的新标签页。基于生态认证集（`topic:dsh-plugin` + dsh 命名）
   的发现式搜索：关键词既直查 GitHub、又对认证集的名称/描述做本地软匹配——真插件不再因为关键词
   字面不命中而整批消失（中文词能搜到中文描述的插件）；空搜索直接浏览认证集前 100 名；仅当认证集
   零命中时才降级旧版名称搜索（无徽章行）。认证行带「topic 认证」徽章。一键安装（`pnpm add`
   装进 web profile + 组合行写入 `~/.dsh/cordis.patch.yml` 的受管区块），校验结果确为 DSH 插件
   （否则自动回滚），支持一键卸载。
2. **MCP** —— 设置里的新页面。以 YAML 直接编辑 MCP 服务器列表（每条 stdio 或 Streamable HTTP）；
   保存即写入 `~/.dsh/cordis.patch.yml` 受管区块，经官方 `@deepseek-ai/dsh-mcp-client` 热加载，
   无需重启。每个服务器显示实时状态（fiber 阶段 + 已注册工具数）；手动添加的行只读展示。
3. **技能** —— 设置里的新页面。列出已注册技能并可查看内容；`~/.dsh/skills/` 下的技能可直接在
   页面新建/编辑/删除（写入即被 dsh 监视的技能根目录热注册）。随部署发布的内置 preset 技能
   （不可修改）默认隐藏，并显示隐藏数量。
4. **系统提示词** —— 设置里的新页面。编辑全局人设（order-0 系统提示词段落，对所有会话生效）。
   人设覆盖行始终存在于受管区块——默认为空，即覆盖掉部署 bundle 自带的默认人设——保存即热加载。
   支持 `{{model}}`/`{{cwd}}` 变量。
5. **服务停止/重启** —— 侧栏底部设置按钮旁的紧凑按钮。停止走启动器的优雅退出（会话先落盘）；
   重启由分离的助手进程在旧 pid 退出后以同一命令行（含 execArgv）重新拉起 dsh，页面轮询到
   新进程应答后自动刷新。
6. **文件变更面板** —— 会话头部右上角 ⋯ 菜单里的入口，右侧停靠面板展示会话工作区的
   git 变更（新增/修改/删除/重命名，逐文件彩色 diff，纯只读）。仅当主机有 git 时才显示
   该菜单项；未初始化的工作区会自动 `git init` 并创建基线提交（内联身份配置，不碰全局
   git 配置），变更始终相对基线可见。
7. **终端面板** —— 会话头部右上角 ⋯ 菜单里的入口，面板内可新建/关闭多个 PTY 终端，
   行输入 Enter 执行、Ctrl+C 中断、输出流式显示。基于官方 `terminals` 服务；需要
   宿主组合挂载 `@deepseek-ai/dsh-terminal` 与后端行（`@deepseek-ai/dsh-terminal-bash`），
   否则该菜单项不显示。

   两个面板均为停靠在聊天右侧的真实列（非悬浮）：面板打开时整个应用框架右移收窄，
   聊天列相应变窄、不被遮挡。面板左缘可拖拽调宽（应用框架实时跟随）；面板顶部为
   面包屑栏（会话标题 › 当前面板 + 关闭按钮），其下是横向工具导航行，点击即可在
   文件变更 / 终端之间原地切换。Esc 或「关闭」按钮收起面板。

8. **用量统计** —— 设置里紧跟「模型」后的新分区：基于全部会话日志的 token 用量汇总
   （输入/缓存读/缓存写/输出/推理，适配器上报的精确计数），按模型的调用次数表与
   费用估算（可编辑的美元/百万 token 单价表，内置 DeepSeek 参考价，未定价模型显示
   "—"），近 31 天用量趋势，以及消耗最多的会话。扫描为增量式（按会话记录 last-seq
   缓存于 `$DSH_HOME/dsh-usage-cache.json`）。
9. **会话管理** —— 设置里的新页面。一屏列出所有持久化会话（标题、项目路径、所属
   工作区、创建时间、活跃/已归档徽标），支持筛选（全部/活跃/已归档/残留）、搜索
   （标题/ID/路径）与逐行删除（确认对话框；正在运行的会话拒绝删除——请先关闭）。
   删除按崩溃幂等的顺序清理：工作区记账、投影缓存行、会话日志目录本身（仅支持
   jsonl 后端），以及尽力清理归档集条目。「残留」行（日志已消失的归档 id）删除时
   只做元数据清扫。删除会话即销毁其完整对话日志，不可恢复。
10. **手机访问** —— 设置里的新页面。在局域网内用手机使用完整 DSH 界面：
    独立端口启动带鉴权的反向代理（DSH 主服务仍只监听本机）。扫码 → 输入一次性
    配对码（10 分钟有效、单次使用、按 IP 指数退避防爆破）→ 获得 HttpOnly 设备
    Cookie（HMAC 签名绑定设备，30 天滑动续期）。已配对设备可随时移除；「轮换密钥」
    一键断开所有设备（该操作仅限桌面本机）。默认关闭。传输为局域网 HTTP——
    出门在外请配合 Tailscale 等加密组网使用。

    代理同时前置 HTTP 与 WebSocket 流量（DSH 的事件通道依赖升级握手）：剥离上游
    拒绝的跨源头、逐字节转发上游 101 握手。HTML 外壳以 `cache-control: no-store`
    下发，并携带一个小型 polyfill：`crypto.randomUUID`（浏览器只在安全上下文暴露
    该 API——`http://127.0.0.1` 桌面算安全上下文，局域网 IP 不算——而 DSH 客户端
    每次 RPC 都用它铸造 id，没有垫片手机上会话列表会是空的）。

    手机访问设置页还提供「当前地址」卡片：列出本机所有可达的局域网访问地址
    （实时读取 `os.networkInterfaces()`，绝不硬编码）并附复制按钮。手机永远连不上
    的虚拟网卡占位地址会被过滤（VPN TUN 198.18.0.0/15、链路本地 169.254.0.0/16、
    CGNAT 100.64.0.0/10），配对二维码与卡片只展示真实可用的候选。

11. **消息刻度轨道** —— 会话滚动条旁的细刻度条（仅桌面端）：蓝色 = 用户消息
    （含打断），绿色 = AI 回复，按消息在文档流中的位置等比例摆放。点击刻度跳转
    到对应消息；悬停显示纯内容摘要（时钟、运行统计、按钮文字被结构性排除）；
    滚动时最接近视口的刻度保持高亮；⋯ 菜单打开期间与触屏/窄视口（<760px）下
    自动隐藏。harness 自带的主题化滚动条皮肤保持原样。

### 移动端适配（手机宽度）

本插件自己的全部界面在 760px 以下自动重排：触控友好的按钮尺寸、宽表格横向滚动
（用量/价格）、工具面板（文件变更/终端）变为全屏覆盖而非可调宽侧栏、二维码
随视口缩放、消息刻度轨道整体隐藏（指针精度交互不适合触屏）；宿主设置对话框本身——桌面是 800px 固定模态 + 188px 左侧导航——被重排为全屏
面板 + 顶部横向滑动导航条（通过 DOM 属性打标实现，宿主类名是 CSS-module 哈希、
不改动 harness 源码）。

## 安全说明

- 状态文件 `$DSH_HOME/dsh-base-plugin.json` 含手机访问的 HMAC 密钥，以 `0o600`
  权限写入（启动时会对历史遗留的宽松权限文件做一次性收紧），与 DSH 自带的
  `.credentials.yaml` 同标准。
- 配对：8 字符配对码（约 40 位熵），单次使用、10 分钟有效、按 IP 指数退避
  （2^n 秒，封顶 10 分钟）。Cookie 为 HttpOnly + SameSite=Lax、HMAC-SHA256 签名、
  绑定设备、30 天滑动续期。
- 代理按设计监听 `0.0.0.0`（局域网访问）；上游 DSH 服务必须保持仅监听回环。
  轮换密钥可即时作废所有已签发 Cookie。
- 进程执行全程无 shell（`spawn` 数组参数）；技能名在任何路径拼接前先通过
  kebab-case 契约校验（无路径穿越）；JSON 请求体上限 1 MB。
- WebSocket 升级 socket 的 error/close 处理器在握手空窗期之前就位——手机射频
  在升级中途重置连接，也不会以未捕获的 `'error'` 事件形式击穿整个 dsh 宿主进程。

## 工作原理

- **宿主半边**（入口 `index.js` + `lib/` 功能模块：`routes`、`market`、`installer`、
  `patch`、`git`、`skills-io`、`sessions`、`usage`、`mobile/*`（`server`、`auth`、
  `qr` + 内置二维码库、`pwa`）、`status`、`lifecycle`、`env`、`state`、`pnpm`、
  `terminals-api`）在 DSH web 服务器上提供 `/dsh-base-plugin/api/*`：状态、市场搜索、
  安装/卸载、MCP 配置保存、技能列表/详情/新建/编辑/删除、会话列表/删除、手机访问控制
  （开关/二维码/设备/吊销/轮换）与局域网配对代理本体、服务停止/重启、git 变更与
  PTY 终端流。
- 受管区块同时组合官方 PTY 行（`@deepseek-ai/dsh-terminal` + `dsh-terminal-bash`），装本插件即有终端能力。
- 权威状态存于 `$DSH_HOME/dsh-base-plugin.json`；`~/.dsh/cordis.patch.yml` 中
  `# >>> dsh-base-plugin managed` 标记之间的区块始终由状态重新生成（标记之外的内容逐字节保留）。
  dsh 实时监听该文件，改动无需重启即生效。
- **浏览器半边**（`client.js`）通过标准插槽（`settings.plugins.tab`、`settings.section`）
  注册界面，并经 DSH locale 服务双语化。

## 安装（部署者）

```bash
# 在 dsh web profile（~/.dsh/profiles/web）中
pnpm add /path/to/dsh-base-plugin
# 然后在 ~/.dsh/profiles/web/cordis.patch.yml 追加（不要放 ~/.dsh/cordis.patch.yml——
# home 补丁作用于所有 profile，而 dsh-base-plugin 只在其依赖所在的 profile 可解析）：
#   - insert:
#       - id: dsh-base-plugin
#         name: dsh-base-plugin
```

在 dsh 进程环境设置 `GITHUB_TOKEN` 可提高市场的 GitHub API 限流额度。
